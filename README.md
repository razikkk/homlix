# Homlix Care - Washing Machine Repair React Website

A modern, responsive, high-converting one-page React website for **Homlix Care** (Doorstep Washing Machine Repair & Service).

## 🚀 Features

- **Header & Hero Section**: Atmospheric dark theme, quick value proposition badges, dual CTA buttons (Call Now & WhatsApp), customer review social proof, and custom technician imagery.
- **Brand Marquee**: Smooth infinite scrolling ticker showing major serviced brands (Samsung, LG, Whirlpool, Bosch, IFB, Godrej, Haier, Panasonic, Siemens, etc.).
- **Complete Care Services**: 4 dedicated service cards (Top Load, Front Load, Semi-Automatic, Installation & Uninstallation) with direct booking actions.
- **Why Choose Homlix Care**: 4 service pillars and a frosted glassmorphic guarantee card on a stainless steel drum background.
- **How It Works**: 4-step connected timeline with numbered badges and custom script typography.
- **Interactive FAQ**: Collapsible accordion covering warranties, pricing, turnaround times, and spare parts.
- **Interactive Booking Modal**: Complete booking flow with brand selector, issue categorization, time slot picker, and celebration confetti.
- **Multi-Channel Footer**: Phone, Email, Vellore Location, legal disclaimers, and sticky floating action buttons.

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **Vanilla CSS (Design Tokens, Glassmorphism, Responsive Grid)**
- **Lucide Icons**
- **Canvas Confetti**
- **Google Fonts (Inter, Plus Jakarta Sans, Caveat, Kalam)**

## 📦 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
